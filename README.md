AI-powered job search & career operations pipeline for resume tailoring, application tracking, and automated outreach.

---

## 🌟 Key Features

- 📄 **AI Resume Tailoring**: Customizes resumes to match target job descriptions using LLMs.
- 📊 **Application Tracking System**: Kanban board tracking applied, interviewing, and offered positions.
- ✉️ **Cold Email Generation**: Generates personalized outreach messages for recruiters and hiring managers.
- 🤖 **Autonomous Job Scraper**: Aggregates job postings across LinkedIn, Indeed, and target company career sites.

## 🚀 Quick Start

### Prerequisites
- Python 3.9+ / Node.js (depending on module)
- Git

### Installation
```bash
# Clone repository
git clone https://github.com/sohan-a11y/career-ops.git
cd career-ops

# Install dependencies (if python project)
pip install -r requirements.txt
```
